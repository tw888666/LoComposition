# G 组（w=0.012，mix_alpha=0.2）多训练种子比较结果

G 组能耗项：r_G = -0.012 × (0.8 × Σ|τ·q̇| + 0.2 × s × Στ²)，s = 0.17440421040278947。与 F 组（mix_alpha=0.1）只差力矩平方混合比例，其余协议相同。共 252 条正式轨迹，18 组评估条件下所有模型的地形、电机、环境、动力学与首步观测逐项一致。

## 0. 结论（人工解读，脚本重跑不会生成本节）

1. **达标情况比 F 好，但仍不是三个种子都达标。** G 在训练种子 46、48 上四条达标线全部满足，训练种子 47 只差通过数（16/18）。F 组三个种子都没有全部达标。
2. **能耗基本保住。** 三个种子每米机械功 44.77、44.08、45.28 焦耳，都在 46.13 以内。相对 F 高 1.9%（只有 1/3 个种子更低），相对 C 低 10.7%（3/3）。力矩平方积分比 F 再低 4.7%，比 C 低 12.5%。
3. **楼梯：三个种子都达标，种子间更一致。** 楼梯航向均方根 4.63、5.49、2.51 度（F 是 3.05、1.72、6.43），末帧侧偏最大 0.67 米。F 在种子 48 上的楼梯超标被修好了，但种子 46、47 比 F 差一些。
4. **崎岖 1.0 的侧偏修好了，平地 1.0 的侧偏没有修好。** F 的 3 次崎岖 1.0 失败在 G 里都消失了。但 G 的 4 次失败里有 3 次是平地 1.0 末帧侧偏 1.20–1.22 米（航向均方根 9–11 度），训练种子 47 的平地 1.0 航向均方根从 F 的 1.80 度升到 10.82 度。另外训练种子 48 在崎岖 1.0 上出现了一次**摔倒（提前终止）**，这是 F 组没有出现过的失败方式。
5. **整体航向变差。** 跨三个种子，航向均方根比 F 高 31%、比 C 高 34%，主要来自训练种子 47（6.83 度）。初始方向速度误差比 C 高 8%。
6. **总体判断：** 把力矩平方比例从 0.1 提到 0.2，失败的场景从崎岖地形移到了平地 1.0，并没有消除高速平地的慢速侧偏。在三个训练种子下，F 和 G 的差异与种子间波动的量级相当（例如航向 G 相对 F 只有 2/3 个种子变好，但平均值变差 31%），**不能说 G 稳定地优于 F**。
