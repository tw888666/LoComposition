# 能耗拉格朗日约束（L 组）第一次正式训练结果

## 实验设置

- 起点：model_30000。在其基础上微调 5000 次迭代，7500 个并行环境，训练种子 46，学习率固定为 0.00003。这些设置与 A–E 组完全相同。
- 能耗处理：能耗不再作为奖励项，改为约束：平滑机械功率 ≤ 动态上限 $P_{\lim}$。用 PPO-Lagrangian（拉格朗日对偶 PPO）求解，乘子 λ 自动调节。
- 上限调整规则：前 500 次迭代热身，结束时以实测平滑功率作为初始上限。之后每 50 次迭代判断一次：
  - 地形等级 ≥ 0.95×3.2，且速度跟踪奖励 ≥ 0.95×0.80，且约束已满足 → 上限收紧 3%；
  - 任一指标低于参考值的 0.90 倍 → 上限放松 3%。
- 评估：与 A/B/C/E 使用同一评估脚本和同一指标代码。6 个场景 × 评估种子 46/47/48，每个检查点 18 场，共评估 3 个检查点。
- 每米机械功统一用"有效米"计算，即沿初始方向的净前进距离。

## 结论

1. 这次训练没有达到"在不降低性能的前提下进一步降低能耗"的目标。
   - 最终的 model_5000 训练结束时 λ=0，奖励中也没有能耗项，等于没有任何能耗压力。它的每米机械功比 A 高 27.8%，配对区间完全落在正值一侧。
   - 两个中间检查点的每米机械功与 A/C/E 相差都在 ±2% 以内，配对区间都跨过 0，没有可分辨的节能效果。
2. 检查点 3149 是本次训练中最好的模型：18/18 通过，每米机械功与 A/C/E 持平。它的速度跟踪比 E 好，配对区间不跨 0；航向保持比 C 差，区间同样不跨 0。在能耗上，它不比 A–E 中任何一组更好。B 组（能耗权重是基线的 1.5 倍）在能耗上仍然最低。
3. 失败的主要原因在于上限调度和 λ 更新之间的耦合：
   - 上限放松之后，λ 要再过数百次迭代才降下来。在这段时间里，策略持续受到压制，性能一路下滑。
   - 地形等级反应滞后。性能下降后，上限被连续放松到远高于实际功率的位置（最高约 60 瓦），λ 归零，约束完全失效。
   - 第二次崩溃时摔倒终止占比达到 48%。这符合"代价恒为正时，策略可以靠提前终止逃避代价"的风险预判，但仅凭现有数据，还无法确认这是策略主动利用的结果。
4. 本次只有一个训练种子，以上差异不能当作跨训练种子成立的结论。机械功是仿真中的代理指标，不等于真实电池能耗。

## 下一步（需要确认后再改）

1. 上限改为只允许收紧或保持不变。性能下降时最多回退一步，并暂停收紧，不再连续放松。
2. λ 加入比例项（PID 拉格朗日的 `lambda_kp`），让它在超限和放松两个方向上都能更快响应。
3. 以速度跟踪奖励作为主判据，因为它反应快；地形等级只作为不能跌破的下限。
4. 把每步代价改为 $(\bar P_t - P_{\lim})/P_{ref}\cdot\Delta t$，允许取负值，消除策略靠提前终止逃避代价的动机。
5. 改完后先跑一次 1500 次迭代的短训练，确认上限和 λ 不再振荡，再进行 5000 次的正式训练。
